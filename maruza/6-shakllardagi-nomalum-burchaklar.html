Geometrik shakllardagi noma'lum burchaklar

Bir chizmada uchburchak ham, to'rtburchak ham bo'lishi mumkin. Noma'lum burchakni bilgan qoidalarimiz bilan topamiz.

1-qism

Mavzu

Chizmani qanday o'qiymiz
  • \(\angle ABC\) — uchi B da bo'lgan burchak.
  • Bir xil chiziqchalar — teng tomonlar, strelkalar — parallel tomonlar.
  • Tomonga yopishgan burchaklar — tomonning ikki uchidagi burchaklar.
1-qoida · chiziq va nuqtadagi burchaklar
  • To'g'ri chiziqdagi burchaklar yig'indisi 180° ga teng.
  • Vertikal burchaklar teng.
  • Nuqta atrofidagi burchaklar yig'indisi 360° ga teng.
1-misol · kesishgan to'g'ri chiziqlar

AB va CD to'g'ri chiziqlar O nuqtada kesishadi. \(\angle BOC = 38°\). x va y ni toping.

1x va 38° — AB to'g'ri chiziqda: \(x = 180° - 38° = \nat{142°}\).
2y va 38° — vertikal burchaklar: \(y = \nat{38°}\).
2-misol · nuqta atrofidagi burchaklar

O nuqta atrofida to'rtta burchak bor: x, 100°, x va 120°. x ni toping.

1Burchaklar yig'indisi 360°: \(x + x = 360° - 100° - 120° = 140°\).
2\(x = 140° : 2 = \nat{70°}\).
2-qoida · uchburchakning burchaklari
  • Uchburchakning ichki burchaklari yig'indisi 180° ga teng.
  • Teng tomonli uchburchakning 3 ta teng tomoni va 3 ta teng burchagi bor. Har bir burchagi 60° ga teng.
  • Teng yonli uchburchakning 2 ta teng tomoni va 2 ta teng burchagi bor. Uning teng tomonlari qarshisidagi burchaklari teng.
  • To'g'ri burchakli uchburchak bitta to'g'ri burchakka ega. Uning qolgan 2 burchagining yig'indisi 90° ga teng.
1-misol · teng yonli uchburchak

ABC — teng yonli uchburchak, AB = BC, \(\angle B = 40°\). x va y ni toping.

1Teng yonli uchburchakda x = y.
2\(x + y = 180° - 40° = 140°\).
3\(x = y = 140° : 2 = \nat{70°}\).
2-misol · to'g'ri burchakli uchburchak

ABC uchburchakda \(\angle C = 90°\), \(\angle B = 34°\). \(\angle A\) ni toping.

1Qolgan ikki burchak yig'indisi 90°: \(\angle A + \angle B = 90°\).
2\(\angle A = 90° - 34° = \nat{56°}\).
3-qoida · to'rtburchakning burchaklari
  • Kvadrat va to'g'ri to'rtburchakning har bir burchagi 90° ga teng.
  • Parallelogrammning (rombning): a) ixtiyoriy tomoniga yopishgan burchaklari yig'indisi 180° ga teng; b) qarama-qarshi burchaklari teng.
  • Trapetsiyaning har bir yon tomoniga yopishgan burchaklari yig'indisi 180° ga teng.
1-misol · parallelogramm

ABCD — parallelogramm, \(\angle A = 65°\). b, c va d burchaklarni toping.

1AB tomoniga yopishgan burchaklar: \(b = 180° - 65° = \nat{115°}\).
2Qarama-qarshi burchaklar teng: \(c = \nat{65°}\), \(d = b = \nat{115°}\).
2-misol · trapetsiya

ABCD — trapetsiya, AB va DC — asoslari. \(\angle A = 72°\), \(\angle B = 58°\). c va d ni toping.

1AD yon tomoniga yopishgan burchaklar: \(d = 180° - 72° = \nat{108°}\).
2BC yon tomoniga yopishgan burchaklar: \(c = 180° - 58° = \nat{122°}\).
Chizmada shakllar ko'p bo'lsa, qaysi burchakdan boshlayman?
Ish tartibi

Ma'lum burchakdan boshlang. Har qadamda bitta burchak toping — izlanganiga yetguncha.

1-misol · to'g'ri to'rtburchak va kesma

ABCD — to'g'ri to'rtburchak. E nuqta DC tomonda yotadi, \(\angle AEC = 130°\). \(\angle EAB\) ni toping.

1DC — to'g'ri chiziq: \(\angle AED = 180° - 130° = 50°\).
2ADE uchburchakda \(\angle D = 90°\): \(\angle DAE = 180° - 90° - 50° = 40°\).
3\(\angle A = 90°\) (to'g'ri to'rtburchak): \(\angle EAB = 90° - 40° = \nat{50°}\).
2-misol · ikki uchburchak va vertikal burchaklar

AB va CD to'g'ri chiziqlar O nuqtada kesishadi. \(\angle A = 50°\), \(\angle C = 60°\), \(\angle B = 65°\). \(\angle D\) ni toping.

1AOC uchburchakda: \(\angle AOC = 180° - 50° - 60° = 70°\).
2Vertikal burchaklar teng: \(\angle BOD = 70°\).
3BOD uchburchakda: \(\angle D = 180° - 65° - 70° = \nat{45°}\).
2-qism

Misollar ishlash

Topgan burchagimni darrov chizmaga yozib qo'yaman — keyingi qadamda kerak bo'ladi.
1-misol · parallelogramm va diagonal

ABCD — parallelogramm, BD — uning diagonali. \(\angle A = 70°\), \(\angle ADB = 45°\). \(\angle DBC\) ni toping.

1ABD uchburchakda: \(\angle ABD = 180° - 70° - 45° = 65°\). (Uchburchak burchaklari yig'indisi 180°.)
2\(\angle ABC = 180° - 70° = 110°\). (Parallelogrammda AB tomoniga yopishgan burchaklar yig'indisi 180°.)
3\(\angle DBC = 110° - 65° = \nat{45°}\).
2-misol · trapetsiya ichida teng yonli uchburchak

ABCD — trapetsiya, AB va DC — uning asoslari. E nuqta AB asosda yotadi va AD = DE. \(\angle A = 68°\). \(a = \angle ADE\) va \(b = \angle EDC\) ni toping.

1AD = DE, demak qarshisidagi burchaklar teng: \(\angle DEA = \angle A = 68°\).
2\(a = \angle ADE = 180° - 68° - 68° = \nat{44°}\).
3\(\angle ADC = 180° - 68° = 112°\). (Trapetsiyaning AD yon tomoniga yopishgan burchaklar.)
4\(b = \angle EDC = 112° - 44° = \nat{68°}\).
3-misol · kvadrat va teng tomonli uchburchak

ABCD — kvadrat, DCE — teng tomonli uchburchak. A va E nuqtalar tutashtirilgan. \(\angle DAE\) ni toping.

1D nuqtadagi burchak ikki bo'lakdan iborat: \(\angle ADE = 90° + 60° = 150°\). (Kvadrat burchagi va teng tomonli uchburchak burchagi.)
2AD = DC (kvadrat tomonlari), DC = DE (teng tomonli uchburchak tomonlari). Demak, AD = DE: ADE teng yonli.
3\(\angle DAE = \angle DEA = (180° - 150°) : 2 = \nat{15°}\).
Shu yerda ko'pchilik adashadi.
Diqqat!
  1. Teng yonli uchburchakda teng burchaklar — teng tomonlar qarshisida turadi. Teng tomonlar orasidagi burchak boshqacha bo'lishi mumkin.
  2. Qarama-qarshi burchaklar parallelogrammda (rombda, to'g'ri to'rtburchakda, kvadratda) teng. Trapetsiyada qarama-qarshi burchaklarni teng deb olmang — u parallelogramm emas.
  3. Burchakni ko'z bilan chamalamang — har bir sonni hisoblab toping.
3-qism

Mustahkamlash

  1. AB — to'g'ri chiziq. x ni toping.
  2. AB va CD to'g'ri chiziqlar O nuqtada kesishadi, \(\angle AOC = 128°\). a, b va c ni toping.
  3. O nuqta atrofidagi x burchakni toping.
  4. KLM — teng yonli uchburchak, KL = LM, \(\angle K = 52°\). \(\angle L\) ni toping.
  5. ABCD — romb, \(\angle A = 76°\). b, c va d ni toping.
  6. ABCD — trapetsiya, AB va DC — asoslari. \(\angle A = 63°\), \(\angle B = 81°\). c va d ni toping.
  7. ABCD — to'g'ri to'rtburchak, AC — diagonal, \(\angle BAC = 34°\). \(a = \angle ACB\) va \(b = \angle CAD\) ni toping.
  8. ABC uchburchakda D nuqta BC tomonda yotadi. \(\angle B = 50°\), \(\angle BAD = 40°\), \(\angle C = 35°\). \(a = \angle ADC\) va \(b = \angle DAC\) ni toping.
4-qism

Mustaqil ish

  1. ABCD — romb, AC — diagonal, \(\angle ABC = 124°\). \(a = \angle BAC\) va \(b = \angle CAD\) ni toping.
  2. ABCD — kvadrat, ABE — kvadrat ichidagi teng tomonli uchburchak. \(a = \angle EAD\), \(c = \angle ADE\) va \(\angle EDC\) ni toping. (Maslahat: AB, AD va AE tomonlarni solishtiring.)
  3. ABC uchburchakning BC tomoni D nuqtagacha davom ettirilgan. \(\angle A = 70°\), \(\angle ACD = 128°\). \(\angle B\) ni toping.
  4. O nuqtada kvadrat OABC, teng tomonli uchburchak OCD va parallelogramm ODEF uchrashadi. \(\angle E = 115°\). x ni toping. (Maslahat: O nuqta atrofida 4 ta burchak bor.)
  5. Xatoni toping. ABC — teng yonli uchburchak, AB = AC, \(\angle B = 40°\). Sardor shunday yozdi: «\(\angle A = 40°\), chunki teng yonli; \(\angle C = 180° - 40° - 40° = 100°\)». Sardorning xatosi nimada? To'g'ri javobni toping.
  6. Qiyinroq. ABCD — parallelogramm, BD — diagonal, AB = BD. \(\angle A = 65°\). \(\angle DBC\) ni toping.
5-qism

Javoblar

Mustahkamlash

1-masala\(x = 180° - 52° - 61° = 67°\).
2-masala\(a = 180° - 128° = 52°\) (to'g'ri chiziq); \(b = a = 52°\), \(c = 128°\) (vertikal burchaklar).
3-masala\(x = 360° - 85° - 110° - 95° = 70°\).
4-masala\(\angle M = \angle K = 52°\); \(\angle L = 180° - 52° - 52° = 76°\).
5-masala\(b = 180° - 76° = 104°\); \(c = 76°\), \(d = 104°\) (qarama-qarshi burchaklar).
6-masala\(d = 180° - 63° = 117°\) (AD yon tomon); \(c = 180° - 81° = 99°\) (BC yon tomon).
7-masalaABC uchburchakda \(\angle B = 90°\): \(a = 180° - 90° - 34° = 56°\). \(\angle A = 90°\): \(b = 90° - 34° = 56°\).
8-masalaABD uchburchakda: \(\angle ADB = 180° - 50° - 40° = 90°\). BC — to'g'ri chiziq: \(a = 180° - 90° = 90°\). ADC uchburchakda: \(b = 180° - 90° - 35° = 55°\).

Mustaqil ish

1-masalaAB = BC (romb tomonlari) — ABC teng yonli: \(a = (180° - 124°) : 2 = 28°\). \(\angle BAD = 180° - 124° = 56°\), \(b = 56° - 28° = 28°\).
2-masala\(\angle EAB = 60°\), \(a = 90° - 60° = 30°\). AD = AB = AE — ADE teng yonli: \(c = (180° - 30°) : 2 = 75°\). \(\angle EDC = 90° - 75° = 15°\).
3-masala\(\angle ACB = 180° - 128° = 52°\) (to'g'ri chiziq); \(\angle B = 180° - 70° - 52° = 58°\).
4-masala\(\angle DOF = \angle E = 115°\) (parallelogrammning qarama-qarshi burchaklari). \(x = 360° - 90° - 60° - 115° = 95°\).
5-masalaTeng tomonlar AB va AC; ularning qarshisidagi burchaklar — B va C. Demak, \(\angle C = \angle B = 40°\), \(\angle A = 180° - 40° - 40° = 100°\). Sardor A burchakni teng deb oldi — u teng tomonlar orasida turadi.
6-masalaABD teng yonli (AB = BD): \(\angle ADB = \angle A = 65°\); \(\angle ABD = 180° - 65° - 65° = 50°\). \(\angle ABC = 180° - 65° = 115°\); \(\angle DBC = 115° - 50° = 65°\).
