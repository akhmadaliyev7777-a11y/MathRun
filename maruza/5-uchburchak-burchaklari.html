Uchburchakning burchaklari

Har qanday uchburchakning uchala burchagi qo'shilsa, 180° chiqadi. Shu qoida yordamida noma'lum burchaklarni topamiz: oddiy uchburchakda, teng yonli va to'g'ri burchakli uchburchakda, bir nechta uchburchak va to'g'ri chiziqdan iborat shakllarda.

1Eslab olaylik

Eslab olaylik
  • To'g'ri chiziqda bir nuqtada yotgan burchaklar yig'indisi 180°; qo'shni burchaklar yig'indisi ham 180°.
  • To'g'ri burchak — 90°.
  • Teng yonli uchburchakda teng tomonlar qarshisidagi (asosdagi) ikki burchak teng.
  • Teng tomonli uchburchakning uchta teng tomoni va uchta teng burchagi bor. Uning har bir burchagi 60° ga teng.

2Qoidalar

1-qoida · burchaklar yig'indisi

Uchburchakning burchaklari yig'indisi 180° ga teng.

\(\angle a + \angle b + \angle c = 180°\)

Namuna · uchta burchak to'g'ri chiziqda

Qog'ozdan uchburchak qirqib olamiz va uchala uchi bir tomondagi bitta nuqtaga tushadigan qilib buklaymiz. a, b va c burchaklar yonma-yon yotib, to'g'ri chiziq hosil qiladi.

Uchburchak burchaklari a, b, c

Yonma-yon terilsa — to'g'ri chiziq: a + c + b = 180°

Transportir bilan o'lchasak, masalan: a = 55°, b = 65°, c = 60°; \(55° + 65° + 60° = \nat{180°}\).

Usul · noma'lum burchak

\(40° + 75° + \angle M = 180°\)

\(\angle M = 180° - 40° - 75° = 65°\)

Namuna · ikki xil uchburchak

\(\angle M = 180° - 40° - 75° = \nat{65°}\)

\(\angle U = 180° - 115° - 27° = \nat{38°}\)

2-qoida · teng yonli uchburchak

Teng yonli uchburchakning teng tomonlari qarshisidagi burchaklari teng bo'ladi.

Usul · teng yonli uchburchakda burchak topish
  • Uchidagi burchak berilsa: \(\angle Q = \angle R\); \(\angle Q + \angle R = 180° - 52° = 128°\); \(\angle Q = 128° : 2 = 64°\).
  • Asosdagi burchak berilsa: \(\angle F = \angle E = 34°\); \(\angle D = 180° - 34° - 34° = 112°\).
Namuna · PQ = PR va DE = DF

\(\angle Q = \angle R = (180° - 52°) : 2 = 128° : 2 = \nat{64°}\)

\(\angle F = \angle E = 34°\); \(\angle D = 180° - 2 \cdot 34° = \nat{112°}\)

Usul · to'g'ri burchakli uchburchak

To'g'ri burchak 90°: \(\angle I = 180° - 90° - 58° = 32°\).

Teng yonli bo'lsa: ikki teng burchak yig'indisi \(180° - 90° = 90°\), har biri \(90° : 2 = 45°\).

Namuna · ∠G = 90°

\(\angle I = 90° - 58° = \nat{32°}\). Tekshiramiz: \(90° + 58° + 32° = 180°\).

Usul · bir nechta uchburchak va to'g'ri chiziq

Uchburchakning burchaklari yig'indisi 180° ga teng.

Qo'shni burchaklar yig'indisi 180° ga teng.

Avval uchburchakdagi noma'lum burchakni, keyin unga qo'shni burchakni topamiz.

Namuna · BCD — to'g'ri chiziq, x ni topamiz
1-usul
\(\angle ACD = 180° - 64° - 52° = 64°\)
\(x = 180° - 64° = \nat{116°}\)
2-usul
x — ACD uchburchakning tashqi burchagi:
\(x = 64° + 52° = \nat{116°}\)

2-usul nega to'g'ri: \(x + \angle ACD = 180°\) va \(64° + 52° + \angle ACD = 180°\). Demak, \(x = 64° + 52°\).

4Namunalar

Namuna 1 · teng yonli uchburchak va to'g'ri chiziq

AB = AC, ∠BAC = 40°, B, C, D bitta to'g'ri chiziqda. ∠ACD ni topamiz.

1Asosdagi burchaklar: \(\angle B = \angle ACB = (180° - 40°) : 2 = 70°\).
2To'g'ri chiziqda: \(\angle ACD = 180° - 70° = \nat{110°}\).
3Tekshiruv (tashqi burchak): \(40° + 70° = 110°\) ✓
Namuna 2 · balandlik ikki uchburchakka bo'ladi

ABC uchburchakda ∠B = 55°, ∠C = 40°, AD ⊥ BC. ∠BAD va ∠DAC ni topamiz.

1ABD uchburchakda ∠D = 90°: \(\angle BAD = 90° - 55° = \nat{35°}\).
2ADC uchburchakda: \(\angle DAC = 90° - 40° = \nat{50°}\).
3Tekshiruv: \(\angle BAC = 35° + 50° = 85°\) va \(180° - 55° - 40° = 85°\) ✓

5Diqqat! Ko'p uchraydigan xatolar

Asosdagi burchak 34° bo'lsa, u ikkita — uchidagi burchak 180° − 2 · 34° bo'ladi, 34° ni ikkiga bo'lib o'tirmaymiz.
Xato ⟶ To'g'ri
  1. Ikkiga bo'lishni unutish.
    uchidagi 52°: asosdagi = 180° − 52° = 128°  →  128° : 2 = 64°
  2. Asosdagi burchak berilganda ham ikkiga bo'lish.
    asosdagi 34°: uchidagi = (180° − 34°) : 2 = 73°  →  180° − 2 · 34° = 112°
  3. To'g'ri burchakli uchburchakda 90° ni unutish.
    ∠I = 180° − 58° = 122°  →  ∠I = 180° − 90° − 58° = 32°
  4. Tashqi burchakni ichki burchak deb olish.
    x = ∠ACD = 64°  →  x — qo'shni burchak: 180° − 64° = 116°
  5. Ikki to'g'ri yoki o'tmas burchakli uchburchak chizishga urinish.
    90°, 95° va yana bitta burchak  →  90° + 95° = 185° > 180° — bunday uchburchak yo'q

7Matnli masalalar

Masalalarni yeching
  1. Uyning tomi teng yonli uchburchak shaklida, asosdagi burchaklari 35° dan. Tomning uchidagi burchak necha gradus?
    Javobni ko'rish\(180° - 2 \cdot 35° = 110°\).
  2. Narvon devorga suyalgan; devor yerga tik. Narvon yer bilan 68° li burchak hosil qiladi. Narvon devor bilan qanday burchak hosil qiladi?
    Javobni ko'rishTo'g'ri burchakli uchburchak: \(90° - 68° = 22°\).
  3. Bayroqcha teng yonli uchburchak, uchidagi burchagi 44°. Asosdagi burchaklari?
    Javobni ko'rish\((180° - 44°) : 2 = 68°\) dan.
  4. Uchburchak burchaklari 2 : 3 : 4 nisbatda. Har bir burchakni toping.
    Javobni ko'rishJami 9 bo'lak: \(180° : 9 = 20°\). Burchaklar: 40°, 60°, 80°.
  5. Uchburchakning bir burchagi 40°, qolgan ikkitasidan biri ikkinchisidan 20° katta. Ularni toping.
    Javobni ko'rish\(180° - 40° = 140°\); \((140° - 20°) : 2 = 60°\) va \(60° + 20° = 80°\).

8O'ylab ko'ring

Qiyin masala · teng yonli va teng tomonli

ABC — teng yonli uchburchak (AB = AC), ∠BAC = 50°. DBC — teng tomonli uchburchak, u BC tomonning narigi tarafida. ∠ACD ni toping.

Javobni ko'rish\(\angle ACB = (180° - 50°) : 2 = 65°\); \(\angle BCD = 60°\); \(\angle ACD = 65° + 60° = 125°\).
Matematika kundaligi · qaysi uchburchak bor?

Uch o'quvchi bahslashdi. Nilufar: «bitta o'tmas va ikkita o'tkir burchakli uchburchak bor». Jasur: «bitta to'g'ri va bitta o'tmas burchakli uchburchak bor». Kamola: «ikkita to'g'ri burchakli uchburchak bor». Kim haq?

Javobni ko'rishFaqat Nilufar haq (masalan 120°, 35°, 25°). Jasurda \(90° + \text{o'tmas} > 180°\), Kamolada \(90° + 90° = 180°\) — uchinchi burchakka joy qolmaydi.

9O'zingizni tekshiring

  • Uchburchak burchaklari yig'indisi 180° ekanini bilaman va ko'rsata olaman.
  • Ikki burchakka ko'ra uchinchisini topa olaman.
  • Teng yonli, to'g'ri burchakli va teng tomonli uchburchaklarning burchaklarini topa olaman.
  • Bir nechta uchburchak va to'g'ri chiziqdan iborat shakllarda noma'lum burchakni topa olaman.
